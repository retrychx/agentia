# 代码评审 Rubric（评审维度与定级标准）

按四个维度逐项检查，每条发现给出 `file` / `line` / `severity` / `title` / `detail`。

## 维度

1. **安全**：硬编码凭据、弱加密/弱哈希、注入面、路径穿越、传输安全（TLS 校验）。
2. **正确性**：并发（check-then-act、共享可变状态）、边界条件、错误吞噬。
3. **健壮性**：外部输入是否校验、失败路径是否可诊断。
4. **可维护性**：魔法数、重复逻辑、命名与注释是否诚实。

## 严重度

- `critical`：可直接被利用或造成资损（硬编码口令、路径穿越、注入）。
- `major`：真实风险但需条件触发（弱哈希、竞态、关闭 TLS 校验）。
- `minor`：影响可维护性/可诊断性。

## 定级（riskLevel）

- 任一 `critical` → `high`；
- 无 `critical` 但有 `major` → `medium`；
- 仅 `minor` → `low`。
